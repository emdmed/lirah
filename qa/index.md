# QA recipes

One recipe per feature. `npm run qa` runs every recipe linked below, and `npm run qa -- <word>` runs the ones whose file name contains the word. A feature without a link has no recipe yet. Opus writes recipes with `/qa-recipes <feature>` (see `qa/README.md`).

|---|---|---|---|
| Terminal | [terminal](recipes/terminal.md) | shell starts in the project, runs commands | 2026-11-06 |
| File tree | [file-tree](recipes/file-tree.md) | lists project files, opens a folder | 2026-11-06 |
| Tabs | [tabs](recipes/tabs.md) | new tab from a starred project, rename, switch, close | 2026-11-06 |
| Tasks | [tasks](recipes/tasks.md) | add, mark done, delete | 2026-11-06 |
| Settings | [settings](recipes/settings.md) | open Settings, switch theme, close | 2026-11-06 |

| Bookmarks (starred projects) | [bookmarks](recipes/bookmarks.md) | star a folder with a name, starred list, Ctrl+P filter and jump | 2026-11-06 |
| Command palette | [command-palette](recipes/command-palette.md) | open with `:`, filter, `term` opens a shell in terminal 2, `tab` opens a tab | 2026-11-06 |
