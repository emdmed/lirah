# File tree

The files pane shows the project's files, and folders open on click.

## Setup
Run `lirah tabs open ~/project`, then `sleep 2`.

## Steps
1. Snapshot and find the file tree.
   **Expect:** entries for `src` and `README.md`.
2. Click `src`.
   **Expect:** `index.js` and `util.js` appear in the tree.
